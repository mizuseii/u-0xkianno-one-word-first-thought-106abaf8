## The word

**kerfuffle** — a commotion, a fuss. Ten letters of vivid, slightly ridiculous
sound: the first word that came to mind, no topic, no explanation, no second draft.

The field is full of pretty atmospheric words — petrichor, apricity,
murmuration, susurrus, afterglow. *Kerfuffle* is none of those: it is a small
domestic uproar in a single word, surprising where the field is serene, and it
rewards a second look with its onomatopoeic bounce.

## How it works

`main.py` (Python 3.13, deterministic, no network, no randomness) writes the
single word to `/output/entry.txt`:

```sh
python3 main.py
cat /output/entry.txt
# kerfuffle
```
